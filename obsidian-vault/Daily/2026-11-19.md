# 2026-11-19 - Memory pressure, BIOS, and a portable research toolkit

## Problem

The laptop was not slow because of drivers. Right after boot it committed
**14.9 GB on 7.7 GB of physical RAM**, so every `Get-CimInstance`, `DISM` and
`SFC` call failed with `0x8007000e` (not enough memory resources).

## Root causes found

| Cause | Size | Fix |
|---|---|---|
| `vmmemWSL` holding half of RAM | 2.9 GB | `.wslconfig` capped at 2 GB + `wsl --shutdown` |
| 15 auto-start services | ~2.8 GB | `tools/trim-services.ps1 -Tier 2 -Apply -StopNow` |
| Windows reopening apps at sign-in | 1.1 GB | `RestartApps = 0` |
| Codex sandbox service | 1.2 GB | registry `Start = 3` (Set-Service is denied) |

## Result

```
commit   14.9 GB -> 9.5 GB      (-36%)
free RAM  0.66 GB -> 1.44 GB
processes    358 -> 268
```

## Findings worth remembering

- **Packaged services refuse `Set-Service` even elevated.** Their security
  descriptor grants only Authenticated Users and the package SID. The registry
  value `HKLM\SYSTEM\CurrentControlSet\Services\<name>\Start` is writable, and
  `3` means Manual.
- **`sihost.exe` as a parent process means app restore, not autostart.** There
  is no Run key to find. `HKCU\...\WinNT\CurrentVersion\Winlogon\RestartApps = 0`.
- **Search engines block scripts but not browsers.** Google needs JavaScript,
  Bing returns unrelated filler, DuckDuckGo serves a bot challenge, and no
  public SearXNG instance answered. A real browser gets through every one.

## Hardware

- **RAM**: Lenovo PSREF confirms *"Up to 12GB (4GB soldered + 8GB SO-DIMM)
  DDR4-2666"*, one slot. Current: 4GB Samsung soldered + 4GB Crucial
  `CT4G4SFS8266` in the slot. Replace the Crucial with 8GB.
- **BIOS**: running `EMCN42WW` (2020-10-28). Latest is **`EMCN60WW`**
  (2024-05-27): https://download.lenovo.com/consumer/mobiles/emcn60ww.exe
  Changelog: CVE-2023-32282, plus Intel microcode updates and ~20 more CVEs
  across 57-59. Applies to 14IIL05 / 15IIL05 / 17IIL05 / V17-IIL.
- **8GB DDR4-2666 SODIMM, UK, 2026-11-19**: Timetec £51.99, Origin Storage
  (Ebuyer) £58.00, Integral £60.95, Mr Memory £62.40, Crucial CT8G4SFS8266
  £63.00. DDR4 is end-of-life, so prices are roughly 2-3x what they were in 2024.
