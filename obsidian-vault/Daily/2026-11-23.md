# 2026-11-23 - Idle commit hogs, GitHub credential audit

## Problem

Three days after the 2026-11-19 fix, commit charge had climbed back to
**17.9 GB of a 20.2 GB limit** (free physical 1.07 GB). The 2026-11-19
trim was still in place, so something else was holding commit.

## Root causes found

| Cause | Commit held | Autostart? | Action |
|---|---|---|---|
| `ollama app` + `ollama serve`, **no model loaded** | 3.6 GB | Startup folder `Ollama.lnk` | Stopped, shortcut moved to backup (Tier 2 = on demand) |
| `ChatGPT.exe` = **OpenAI.Codex package**, 14 processes | 1.17 GB | **None** | Killed; no respawn in 75 s |
| Microsoft Copilot app, 9 processes | ~0.3 GB | None found | Killed; no respawn in 100 s |
| Unresponsive `SystemSettings` window | 0.19 GB | n/a | Killed |

### The "ChatGPT returns after reboot" theory was wrong

The 14 `ChatGPT.exe` processes are the **Codex** MSIX package
(`OpenAI.Codex_26.1111.9664.0`). Evidence against an autostart:

- manifest startup task: `Enabled="false"`
- no `Run` / `RunOnce` value, no Startup folder entry
- no scheduled task, no service dependency
- `RestartApps = 0` present and effective
- start time 19/11 17:26:18 = **5 minutes after boot**, not at sign-in
  (a startup task fires within seconds)

It had simply been left running. Killed, nothing restarted it.

## GitHub credential audit

`cmdkey /list` had 4 GitHub targets. Reading them via `CredRead` (not
`cmdkey`, which cannot show secrets) showed **two distinct live tokens**:

| Target | Token | Scopes | Result |
|---|---|---|---|
| `git:https://github.com` | `gho_XxIp…` | repo, workflow, gist, org, … | **kept** (git works) |
| `git:https://jayprophit@github.com` | `gho_XxIp…` (same) | same | deleted |
| `GitHub for Visual Studio - …` | `gho_XxIp…` (same) | same | deleted |
| `GitHub - https://api.github.com/jayprophit` | `gho_hV2Y…` (different) | repo, user, workflow | deleted |

- The earlier "no entries left" result was a **false negative**: I used
  `Select-String -Pattern 'Target:.*github' -SimpleMatch`, which searches
  for that literal string. Lesson: never combine a regex with `-SimpleMatch`.
- `gho_hV2Y…` was printed during the audit, so it is treated as exposed:
  entry deleted locally, **revoke the issuing OAuth app on GitHub**.
- The originally leaked `gho_zjsFDSeR…` (2026-11-19) is already revoked.

## Still needs elevation / a human

  (126 MB): `Set-Service` returned **Access is denied** from this shell.
- `AnyDesk` and `TeamViewer` both run Auto (~67 MB). Left alone — stopping
  remote access without asking could lock the user out.
- BIOS EMCN42WW -> EMCN60WW still not flashed.
- RAM still 8 GB; 8 GB DDR4-2666 SO-DIMM not bought.

## Never do again

- Do not assume a process name identifies an app: `ChatGPT.exe` was Codex.
- Do not trust an empty `cmdkey` filter; verify with `CredRead` and a real
  auth call.
- `commit`, not working set, is the metric that matters on an 8 GB / 20 GB
  pagefile machine. `ollama app` showed 21 MB WS but 3.6 GB commit.
